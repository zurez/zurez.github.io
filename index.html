📏 Custom Metrics

ToolFlowMetric

Domain-specific validation for banking agent tool sequences

backend/evaluations/metrics/tool_flow_metric.py
from deepeval.metrics import BaseMetric
from deepeval.test_case import LLMTestCase

class ToolFlowMetric(BaseMetric):
    """Validates that agent called expected tool sequence"""
    
    def __init__(self, threshold=0.8, strict_order=False):
        self.threshold = threshold
        self.strict_order = strict_order
        self.score = 0.0
        self.success = False

Validation Logic

  • Checks if all required tools were called
  • Optionally validates tool call order
  • Provides partial credit for partial matches

⚙️ Metric Implementation

def measure(self, test_case: LLMTestCase) -> float:
    # Extract expected vs actual tool calls
    expected_flow = test_case.additional_metadata.get("expected_tool_flow", [])
    actual_tools = test_case.additional_metadata.get("actual_tool_calls", [])
    
    # Validate tool calls
    missing = [t for t in expected_flow if t not in actual_tools]
    extra = [t for t in actual_tools if t not in expected_flow]
    
    if not missing and not extra:
        self.score = 1.0  # Perfect match
        self.success = True
        self.reason = f"Perfect match: {' → '.join(actual_tools)}"
    elif not missing:
        self.score = 0.9  # All required + extras
        self.reason = f"Extra tools: {', '.join(extra)}"
    else:
        # Partial credit
        matched = len([t for t in expected_flow if t in actual_tools])
        self.score = matched / len(expected_flow)
        self.reason = f"Missing: {', '.join(missing)}"
    
    return self.score

from deepeval.metrics import GEval, AnswerRelevancyMetric
from evaluations.metrics.tool_flow_metric import ToolFlowMetric

def get_all_agent_metrics():
    return [
        # 1. Custom: Tool Flow Validation
        ToolFlowMetric(
            threshold=0.8,
            strict_order=False
        ),
        
        # 2. GEval: Task Completion (LLM as judge)
        GEval(
            name="Task Completion",
            criteria="Agent completed the banking request",
            evaluation_params=[INPUT, ACTUAL_OUTPUT, EXPECTED_OUTPUT],
            threshold=0.8
        ),
        
        # 3. Built-in: Answer Relevancy
        AnswerRelevancyMetric(threshold=0.7)
    ]

🚀 Evaluation Script

backend/evaluations/scripts/run_development_eval.py
from deepeval import evaluate
from deepeval.test_case import LLMTestCase
from evaluations.datasets.banking_scenarios import ALL_SINGLE_TURN_GOLDENS
from evaluations.metrics.agent_metrics import get_all_agent_metrics

async def run_evaluation(model_name="gpt-4o"):
    # Run agent on each test case
    test_cases = []
    for golden in ALL_SINGLE_TURN_GOLDENS:
        actual_output, metrics_data = await run_agent(golden.input, model_name)
        
        test_case = LLMTestCase(
            input=golden.input,
            actual_output=actual_output,
            expected_output=golden.expected_output,
            additional_metadata={
                "actual_tool_calls": metrics_data["tool_calls"],
                "expected_tool_flow": golden.additional_metadata["expected_tool_flow"]
            }
        )
        test_cases.append(test_case)
    
    # Evaluate with all metrics
    results = evaluate(
        test_cases=test_cases,
        metrics=get_all_agent_metrics()
    )
    
    return results

⚡ Evaluation Process

Execution Flow

  1. Parallel Execution: All 10 test cases run concurrently (~15 seconds)
  2. Agent Invocation: Each test runs through the banking agent graph
  3. Tool Tracking: Records which tools were called and in what order
  4. Metric Calculation: DeepEval evaluates each test against all 3 metrics
  5. Result Aggregation: Generates JSON report with scores and analysis
Performance: 10 tests × 3 metrics = 30 evaluations in ~15-20 seconds
